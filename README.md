# LATCHI PLAY 3.2

تطبيق Android أصلي (Java) بهوية LATCHI PLAY، بواجهة عربية منظمة مدعومة بواجهة **TMDB** (المعطيات: الأفيشات، القصص، البحث، المواسم والحلقات) وتشغيل فيديو **أصلي 100% عبر Media3/ExoPlayer** — دون WebView ودون iframes.

## البنية الجديدة (TMDB + Providers)

- **TMDB API** للمحتوى والبحث والتفاصيل والمواسم والحلقات (المفتاح مجاني من themoviedb.org ويُدخل من الإعدادات داخل التطبيق).
- **مصادر تشغيل (Providers)** تحوّل العنوان إلى رابط مباشر `mp4 / m3u8` يعمل مباشرة في المشغّل الداخلي:
  - `ArchiveOrgProvider` — أرشيف الإنترنت (ملكية عامة، مجاني، روابط mp4 مباشرة تدعم Range).
  - `PeerTubeProvider` — منصات PeerTube (مفتوحة، مجانية؛ رابط المنصة قابل للتغيير من الإعدادات).
  - `XtreamProvider` — سيرفر IPTV/Xtream الخاص بك (VOD + مسلسلات) — يُضبط من الإعدادات.
  - `TopCinemaaProvider` / `EgyDeadProvider` — تصفح كتالوج الموقعين (رئيسية/أفلام/مسلسلات/بحث) من زر "المواقع".
  - `MyCimaProvider` — مسجّل ويعيد "غير متاح" (الموقع محمي بـ Cloudflare؛ لا نتجاوز الحماية).
- **Failover تلقائي**: المصدر المختار في الإعدادات يُجرَّب أولًا، ثم باقي المصادر المفعّلة، ثم الاحتياطي المجاني — عبر `PlaybackResolver` بمهلة زمنية ومحاولات محدودة.
- الرئيسية: **Hero Banner** (خلفية سينمائية + أزرار مشاهدة/تفاصيل) + متابعة المشاهدة + أحدث الأفلام/المسلسلات + شرائح الأنواع + الرائج + بحث موحّد (TMDB + المواقع) مع دمج وتفادي التكرار.
- تفاصيل سينمائية: Backdrop + قصة + سنة + تقييم + أنواع + طاقم + مخرج (حسب توفرها في المصدر) + مواسم/حلقات بترتيب رقمي وبطاقات مصغّرة مع شريط تقدم.
- المواسم كشرائح، والحلقات تُعرض لكل موسم منفصل؛ "الحلقة التالية" مع عدّاد 5 ثوانٍ (ويعبر بين المواسم تلقائيًا).
- المفضلة، السجل، متابعة المشاهدة (استئناف من آخر موضع — قابل للإيقاف من الإعدادات).
- هاتف عمودي / Android TV أفقي مع دعم الريموت وLeanback.
- تحديث تلقائي اختياري عبر GitHub Releases.

> **حدود شفافة:** لا يستخرج التطبيق روابط مخفية، ولا يتجاوز Cloudflare/DRM/CAPTCHA، ولا يضم أسرار مصدر غير مصرح به. الروابط تُؤخذ فقط من واجهات رسمية/مصرح بها أو من سيرفر تملكه. المحتوى الحديث (2025/2026) يتطلب مصدرًا تملكه أو لديك إذنًا له (مثل سيرفر Xtream خاص) — ولا يوجد مصدر مجاني قانوني له.

## البناء على Codemagic

1. أضف المستودع إلى Codemagic.
2. اختر **Codemagic YAML**.
3. شغّل workflow: `android-debug-apk` للحصول على `LATCHI-PLAY.apk` للتجربة، أو `android-release-aab` للإصدار الموقّع.

## إصدار Google Play الموقّع

أنشئ Variable group في Codemagic باسم `android_signing` وأضف المتغيرات الآتية كـSecure:

| المتغير | القيمة |
|---|---|
| `CM_KEYSTORE` | ملف keystore مشفّر Base64 |
| `CM_KEYSTORE_PASSWORD` | كلمة مرور keystore |
| `CM_KEY_ALIAS` | اسم المفتاح |
| `CM_KEY_PASSWORD` | كلمة مرور المفتاح |

## بعد التثبيت

1. افتح **الإعدادات** داخل التطبيق.
2. أضف مفتاح TMDB (مجاني من themoviedb.org → Settings → API).
3. اختر مصدر التشغيل المفضل (Archive.org افتراضيًا) أو أضف بيانات سيرفر Xtream الخاص بك.
4. تصفّح، افتح التفاصيل، وشاهد مباشرة داخل المشغّل.
